# Partidos Mundial

Este repositorio contiene un script en Python para gestionar los resultados de un grupo del Mundial.

## Archivo principal

- `mundial_group.py`: gestiona equipos, partidos, tabla de posiciones y estadísticas individuales.

## Descripción

El script permite:

- agregar equipos a un grupo
- registrar partidos entre equipos
- calcular puntos, victorias, empates, derrotas, goles a favor y goles en contra
- generar y mostrar la tabla de posiciones ordenada por puntos, diferencia de goles y goles a favor
- mostrar el historial de partidos
- obtener estadísticas detalladas de cada equipo

## Uso

Ejecuta el script con Python:

```bash
python mundial_group.py
```

## Ejemplo

El script incluye un ejemplo de grupo con equipos y partidos registrados, y muestra la tabla de posiciones y estadísticas.
